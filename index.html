Other tools

Other fan sites tackle the same question. Try them if you'd rather tick a wishlist by hand:

  • fortnitepirateshoptoken.org Activation Planner: you tick items and it ranks start dates by coverage. It cites sources and lists assumptions, but uses a fixed shop snapshot.
  • pirateshoptoken.org: today's total free value, with its method explained, plus a countdown and a haul list.
  • pirateshoptoken.com: an activation guide with a date picker and a labelled drop calendar.

What this page adds: a daily automatic refresh, scoring by type preferences instead of only a wishlist, automatic source checks, and uncertainty ranges. Descriptions checked Nov 14, 2026.
